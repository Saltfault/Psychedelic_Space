# Psychedelic Space

Psychedelic Space is a forward-firing space action roguelite made with Godot. Pilot a ship through branching sectors, fight enemies, explore hazardous space, collect upgrades, and survive as long as you can. Ship handling, weapons, sensors, and pilot abilities shape each run.

## Controls

| Action | Keyboard / mouse | Controller |
|---|---|---|
| Thrust | W or Space | A / Cross |
| Fire | Left mouse button | Right trigger |
| Pilot ability | Left Shift | B / Circle |
| Interact | E | X / Square |
| Sector map | Tab | Left shoulder |
| Pause / close a panel | Esc | — |

Keyboard controls can be changed in Options.

## Contributing

- Use Godot 4.7.2 and Git LFS; fetch LFS files before opening the project.
- Keep contributions focused and submit them as a pull request. For bug reports, include reproduction steps and the error message, if any.
- Use Git LFS for large binary assets. Include the asset's source and license information with any new third-party content.
- Do not commit Godot's generated `.godot/` cache.
