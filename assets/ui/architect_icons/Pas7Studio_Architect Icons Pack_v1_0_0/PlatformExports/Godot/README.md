# Godot import example

This is a ready-to-open Godot 4.x project for **Architect Icons Pack v1.0.0**.

1. Open this folder in Godot.
2. Press **F6** to run the demo scene.
3. Use `manifest.json` as the stable platform import contract.

Future platform adapters belong beside `Godot/` under `PlatformExports/`.
